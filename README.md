# Algebra 1 Sessions

An offline practice app for the first topics of Algebra 1: order of operations, negative numbers, evaluating expressions, combining like terms, the distributive property, and one- and two-step equations.

Each session has a warm-up, a short lesson, guided practice with hints, and a 5-question check. Progress is stored on the device only (Progress → Backup to save a copy).

## Install on a phone
Open the GitHub Pages link, then:
- **iPhone:** Safari → Share → Add to Home Screen
- **Android:** Chrome → menu → Install app

After the first visit it works with no connection.

## Updating
After editing `index.html`, bump `VERSION` in `sw.js` (e.g. `alg1-v2`) so installed copies pick up the change.
